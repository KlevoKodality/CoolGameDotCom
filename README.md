# CoolGameDotCom
Я хз чё тут писать
Не опровергнуть закон Ома,
Он справедлив, как аксиома,
И в упрощённом изложении 
Гласит: при данном напряжении
Чем меньше ты сопротивляешься, 
Тем больше током поражаешься.
Но есть трактовка ещё проще,
Она известна даже тёще:
Взявшись рукой за напряжение,
Даёшь возможность прохождения
Тока через твоё сопротивление,
И будет жертвоприношение.
Совет особо любопытному
Исследователю ненасытному:
При изучении процессов
Во избежание эксцессов
Не лезь туда, где ток окажется,
Иначе мало не покажется...
